### 需求概述

针对 `/pin-electronics`，先理解并复述：用户希望知道修改哪些入口会刷新哪些对应值，并结合半导体 ATE（自动测试设备）的业务关系判断应有的联动。本阶段仅分析，未获准实施功能改动。“刷新”暂按界面配置及关联展示更新理解，同时区分浏览器重新加载、配置下发和硬件测量回读。

### 当前实现事实

路由在 `file-transfer-web/src/router/index.ts:115`，实际加载 `src/views/PinElectronicsView/index.vue`。根目录 `pin-electronics/` 为独立 HTML 参考素材，不是该路由的组件。

| 修改入口 | 当前更新结果 |
| --- | --- |
| 顶部 Pin 或电路区 Pin Name | 两处选择同步，DUT Channel 根据固定映射更新；其他参数不随 Pin 切换加载 |
| TimeSet Name / TimeSet | 只修改所选字段，不加载对应的 Period、格式或边沿 |
| Period | 更新 Rate，公式为 1000 / Period(ns)，单位 MHz；D/R 数值不变 |
| Drive Format、Start State | 保存当前选项，没有按格式调整边沿或生成波形 |
| Init State | 保存状态；Driver Mode 为 Drive 时更新电路中的模式文字 |
| D0–D3、R0–R1 | 更新对应数字；Dis 控制该输入的禁用状态并保留数值 |
| Disable Compare | 禁用 Compare Mode、R0/R1、Voh/Vol 相关输入并弱化比较通路，保留原数值 |
| Vih/Vil、Voh/Vol、Vt、Vch/Vcl、Ioh/Iol | 单字段更新，没有自动计算其他电气参数 |
| 电平预设 | 批量覆盖预设中的七项电压参数，不覆盖 Ioh/Iol 或时序 |
| Driver Mode / 继电器 | 模式控件同步，电路文字、开关和高亮按状态更新；没有完整硬件互锁逻辑 |
| Safe HiZ | 切换 HiZ，断开主继电器与 PPMU 继电器 |
| PPMU 弹窗 Apply | 提交强制模式、值、限值和继电器状态，并切换 Driver Mode 到 PPMU |
| Counter 弹窗 Apply | 保存计数边沿与门控时间；读数仍是占位符 — |
| Reset | 恢复整份默认配置并保存 |

统一更新入口是 `usePinSettings.ts:31` 的 update 和第 37 行的 apply。两者替换 shallowRef 的整个 settings 对象触发响应式更新，并写入 localStorage 的 `file-transfer-pin-electronics-v1`。初始化先创建默认值再恢复有效的已保存字段；所以修改 model.ts 中默认值后，已有缓存可能使页面仍显示旧值。Reset 可恢复新的默认值，但会重置整份配置。

路由切换使用 KeepAlive，返回时沿用内存状态；浏览器重新加载才会重新初始化并恢复缓存。该模块没有测试机通信或测量回读，也未与 `/timesetbasic`、`/mio16-timing` 共享配置。

### 行业分析：建议的业务关系，尚未实施

1. Pin/通道决定当前配置对象。若不同 Pin 有独立配置，切换应加载该 Pin 的电平、模式、继电器及当前时序上下文的参数。共享 Pin Group、资源和电平集的范围需按实际设备及测试程序定义。
2. TimeSet 决定时序上下文。切换应加载该 TimeSet 的周期以及当前 Pin 的格式、驱动边沿和比较选通参数。电平通常由独立电平集管理，不能默认随 TimeSet 一起覆盖。
3. Period 改变应刷新 Rate，并重新检查边沿是否落在设备允许的周期范围内。对于绝对时间配置，不应无依据按比例改写所有边沿；当前 D 使用 ps，R 与 Period 使用 ns，比较前必须统一单位。
4. Drive Format 与 Compare Mode 改变，应按目标测试机定义更新有效边沿、校验及预览。edge/window 的比较含义不同，具体 R0/R1 使用规则需要仪器说明；不能仅凭字段名确定。
5. 电气参数各司其职：Vih/Vil 是测试机施加到 DUT 输入的高低电平；Voh/Vol 是判断 DUT 输出的门限；Ioh/Iol、Vt 属于有源负载相关配置；Vch/Vcl 为钳位电压。编辑时主要更新对应配置并检查电气约束，不代表这些数值存在统一的自动换算公式。
6. Drive、HiZ、PPMU 与继电器存在仪器相关的连接和互锁要求。真实设备的生效状态应由下发确认、回读决定，不能以示意图高亮代表硬件已切换。
7. Counter 的测量值必须来自实际采集；Period 推导出的 Rate 是配置频率，不能替代实测计数读数。

### 候选验收场景

- 为 A/B 两个独立 Pin 设置不同 Vih，切换时应恢复各自的值；本项依赖确认独立 Pin 的配置模型。
- 同一 Pin 在两个 TimeSet 下有不同边沿，切换时序上下文应恢复对应配置，独立电平集不被无关覆盖。
- Period 从 500 ns 改为 250 ns，Rate 从 2 MHz 变为 4 MHz；超出新周期的有效边沿需按设备规则提示或拒绝，不能静默缩放。
- 编辑 PPMU 草稿后取消，不改变已提交配置；Apply 提交配置，真实生效状态须在接入设备后单独确认。
