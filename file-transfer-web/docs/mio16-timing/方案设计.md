### 模块与数据流
- `Mio16TimingView/index.vue`：路由组合面，传递当前配置、选中 PIN 与事件。
- `model.ts`：类型、默认示例、有效边沿、格式转换、校验、驱动事件与比较点、导入解析。纯函数，可独立测试。
- `useTimingEditor.ts`：单一配置状态、选中 PIN、本机持久化、JSON 导入导出；所有写操作经过统一接口。
- `components/TimingGrid.vue`：只读 props，通过 select/update/format/edge 事件提交编辑，支持固定 PIN 筛选、A/B 行。
- `components/TimingPreview.vue`：接收 PIN、Period、错误，持有只影响视图的 Periods、缩放与显示模式；Pattern/初态编辑 emit update。
- `mio16.css`：隔离 `.mio-workspace` 样式，暗色仪器界面，表格固定表头、窄屏横向滚动。

### 实现决策
沿用 Timeset Basic 的 D3 `scaleLinear` + Vue SVG 方式，比例尺负责时间映射与反算，Vue 负责交互和路径，无需引入另一个图表框架。新的规则引擎替代旧的近似返回波形。NR 格式双线单独绘制；数据波形使用有序事件，保持状态跨越周期边界。其他格式示意通过数据 1 / 0 两条事件轨迹叠加。

数值编辑实时校验，不对已有边沿做静默缩放。SDR/DDR 切换会按当前 Period 初始化对应 PIN 时间并在界面说明；禁用的配置值保留，避免不必要的数据丢失。导入要求版本、16 个有序唯一 PIN、受支持枚举、有限数字与合法有效边沿；失败保持当前配置。

缩放以视口中心的真实时间为锚点。固定可选周期数控制绘制量；当前仅绘制选中的 PIN，16 通道数据保留在表格。格式示意不宣称电气仿真，R 线为配置位置。原 `/timesetbasic` 源码本轮不修改。

### 验证
纯规则测试覆盖八种格式、数据 0/1、NR 跨周期保持及更新、A/B 偏移、多周期比较点、无效边沿、错误顺序、MUX、格式转换、导入校验。运行完整 vue-tsc 类型检查、Vite 构建，以及浏览器导航/编辑/预览/缩放/持久化交互。完成后独立只读审查。

### 四项修复设计
Pattern 取位索引仅对 DDR_NR 使用 cycle*2+half，2XCLK 使用 cycle。新增 driveMarks 纯函数，将配置沿标记与 driveEvents 电平事件分离；时钟 D0 每周期仅一个共享标记。TimingLane 用短刻度表示边沿，不假设每个边沿一定引起电平翻转。

同类 DDR 的格式转换只调整受约束的 D0，不再重建整组 B。Pin 新增可选 ddrBDriveOn 字段，用于跨时钟格式保留独立 B.D0；导入解析允许并校验该字段，旧 JSON 不带该字段时仍可读取，返回 DDR_NR 使用原有默认 D0。已合法编辑的 B.D1、B.R0 等不丢失。

适配模式以实际 viewportWidth 为基础宽度，按共享 scaleLinear 映射到整幅视口；点击适配令 zoom=1、scrollLeft=0。此后放大沿用适配后的基础宽度，保留原视口中心锚点。

### 格式示意绘图隔离
- `TimingPreview` 保持 16 PIN 共享比例尺与滚动视口；`TimingLane` 接收已有 props，负责通道展示和边沿标注，select 事件不变。

- RC/SBC/DDR_NR 共用双线交叉路径；RH/RL 使用闭合双线加固定返回单线；时钟独立绘制脉冲；NR 保留只在首个 D1 交接的规则。
- 交叉以配置沿为中心，屏幕宽度最多 6 px，受到相邻沿间距限制。D1=D2 退化为零宽度，所有路径从左向右绘制。
- 实际数据波形仍使用原有 `driveEvents` 和阶梯路径。格式示意不依赖 Pattern 或 initial。
- 测试实际编译并服务端渲染 `TimingLane.vue`，检查输出 SVG 的闭合节点、双/单线截面、A/B 更新位置和标注；覆盖零宽脉冲、边界重合及缩放。
