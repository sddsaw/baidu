### 目标与交付范围
基于 Timeset Basic 的编辑表格、D3 时间比例尺、周期拼接及缩放方式，新增独立 `/mio16-timing` 页面及导航，原页面保留。为 MIO16 提供单 Timeset、16 个固定 PIN 的离线编辑与预览。支持八种格式 NR、RH、RL、RC、SBC、DDR_NR、2XCLK_POS、2XCLK_NEG；原输入 `ner` 视作 `neg` 笔误。

### 文档依据
用户提供 `/Users/zhouenbo/Desktop/测试/米哦6/1.png` 至 `11.png`，为《MIO16 Timing Formats 时序格式示意图》截图，引用内部 Confluence，但当前没有原始接口定义或可联调设备。

| 格式 | 驱动行为 | 比较能力 |
| --- | --- | --- |
| NR | D1 写入后保持，D2/D3 无效 | Edge R0 / Window R0、R1 |
| RH | D1 写入，D2 固定返回高 | Edge / Window |
| RL | D1 写入，D2 固定返回低 | Edge / Window |
| RC | D1 写入，D2 返回当前数据反相 | Edge / Window |
| SBC | D0 反相、D1 数据、D2 反相；MUX 禁用 | Edge / Window |
| DDR_NR | A/B 分别 D0、D1，保持至下一次写入 | 仅 Edge，A/B 各 R0 |
| 2XCLK_POS | A/B 各 D1 上升、D2 下降；共享 D0 | 无，仅驱动 |
| 2XCLK_NEG | A/B 各 D1 下降、D2 上升；共享 D0 | 无，仅驱动 |

2XCLK 的 Pattern=1 使能脉冲，Pattern=0 时 POS 保持高、NEG 保持低，依截图实现，不能擅自替换为常见时钟门控默认电平。

### 编辑与预览验收
- Period 输入单位 ns；Periods 默认为 1，可选择多个拼接周期；D3 比例尺、按钮缩放、Ctrl/Command+滚轮缩放、水平滚动。
- PIN 不可改；FORMAT、Compare mode 为下拉；数值为输入框。有效边沿以外显示横杠，不参与时序校验。
- DDR 显示 A/B 两行，时间统一按整个 Period 起点计算，B 位于后半周期；2XCLK 的 B.D0 只读并与 A 同步。
- 驱动顺序 D0≤D1≤D2（仅有效边沿），比较顺序 D3≤R0≤R1（仅适用模式）。没有文档支持的硬件量化步长与最小脉宽不臆造。
- SDR Drive 与 Compare 实际周期互斥。Drive 图上 R 线是配置位置叠加，不是执行仿真；切换 Compare 后检查 D3，无驱动输出。
- 格式示意叠加两种逻辑状态。NR 首个 D1 附近交叉，前半虚线、后半实线，后续周期两条实线保持开放，不反复交叉或周期末闭合。数据波形依据 Pattern 每周期/半周期取一位，允许 NR 后续新数据改变电平。
- Window 每周期 R0、R1 垂直标记，Edge 只有 R0；DDR_NR 每半周期重复 R0。
- 校验错误不绘制该 PIN 的误导性波形，且阻止保存/导出。支持本机保存、载入、严格 JSON 导入与导出；无设备下发按钮。

### 行业对照与有意决策
公开核对来源：[NI-Digital DriveFormat](https://nidigital.readthedocs.io/en/stable/enums.html#nidigital.DriveFormat)、[TimeSetEdgeType](https://nidigital.readthedocs.io/en/stable/enums.html#nidigital.TimeSetEdgeType)。NR 保持、RL 返回低、RH 返回高、SBC 反相包围的核心含义一致；公开 API 亦有第二组数据/返回/采样沿。但八种名称、MIO16 D3 无效限制、2XCLK 禁止比较不代表统一行业标准。

截图 RL/RH 中“另一数据位脉冲方向相反”的文案与固定返回低/高矛盾，采用固定返回定义。NR 保持是保持到下一数据沿，不代表所有后续向量永不改变。原 Timeset Basic 的双线要求保留为格式示意。

### 明确边界
当前是单 Timeset 离线工具，不实现测试机执行、测试结果判定、电压等级、硬件时序量化、.def 文件下发。比较模式在多 Timeset 系统应按 PIN 全局共享；未来增加多 Timeset 时应提升此状态层级。A/B 时间原点、端点相等时硬件优先级、2XCLK 数据为 0 行为及 MUX 约束需以原始 Confluence/API 与设备联调最终确认。

### 四项审查问题的修复结果
1. 2XCLK_POS/NEG 每个 tester cycle 消费一个 Pattern 位，A/B 共用该位；DDR_NR 仍每半周期消费一位。
2. 所有有效驱动沿显示独立的位置标记。D0 不需要产生电平变化也应可见；NR 波形仍只在首个 D1 交叉，不因 D0 增加交叉或长虚线。
3. DDR_NR、2XCLK_POS、2XCLK_NEG 之间切换保留共同时间参数。共享 D0 时暂存独立 B.D0，返回 DDR_NR 恢复。原有 SDR/DDR 时间域切换的初始化规则未扩大本轮修改范围。
4. “适配”显示全部周期并回到横向起点，之后仍可正常放大、缩小；适配状态下周期数或视口宽度变化后仍显示完整范围。

### 格式示意专项修订
本轮仅调整格式示意，不检查或修改实际 Pattern 数据波形。依据用户手绘图与最新 D2 闭合截图：示例 D0=20 ns、D1=50 ns、D2=80 ns，绘图读取配置，不能将 80 写死为默认时间。

| 格式 | 示意画法 |
| --- | --- |
| NR | 首个 D1 处双虚线交接双实线；后续周期保持开放双线，不增加返回沿 |
| RH / RL | 首个 D1 前双虚线；D1 展开双线，D2 上下两线在中心尖角闭合，再接 RH 高位或 RL 低位单线；跨 Period 保持到下一 D1，再展开、闭合 |
| RC | D1 展开数据双线，D2 交叉表示互补转换，随后继续开放双线；不能按 RH/RL 固定合并到高或低 |
| SBC | 首个 D0 前双虚线，从 D0 开始互补包围；D1 转为数据，D2 转回互补；下一周期 D0 表示下一组 surround 值的施加位置 |
| DDR_NR | 每周期 D1 A / D1 B 展示数据更新交叉，更新沿之间及周期边界连续保持双线；D0 与半周期边界不额外返回 |
| 2XCLK_POS / NEG | 保留明确方向的矩形双脉冲，每周期 A/B 各一次；另以不同颜色水平线表示本机定义的 0 状态，并标注含义 |

双线和尖角是格式图形符号，斜线宽度是屏幕表现，不表示实际电平或设备上升下降时间。重合边沿压缩显示，不产生负宽度区段；不推定硬件对同时边沿的优先级。

### 行业对照范围
本轮重新读取 [NI-Digital DriveFormat](https://nidigital.readthedocs.io/en/stable/enums.html#nidigital.DriveFormat)：NR 保持、RL 返回低、RH 返回高、SBC 返回互补的文字定义与对应语义一致。该来源没有规定统一的双线闭合尖角符号，不能证明全部八种 MIO16 格式属于通用标准。RC、DDR_NR、2XCLK 与本机专属限制按用户定义图处理。NR 只画首个 D1 是用户指定的格式简图，不限制实际逐周期更新。
